## 1. Architecture decision

**Freeze the core architecture for planning. Defer the full V1.1 freeze.** The frozen design is a local MCP server using stdio, Canvas/SVG, Three.js, a shared deterministic timeline, browser frame capture, and a rendering adapter that invokes externally provisioned FFmpeg/FFprobe. Container, codec and executable selection remain explicit. The pilot can enable only export profiles cleared for its scope.

The [pilot output decision](singapore-macos-arm64-pilot.md#launch-output) provides a standalone animated SVG path. When qualifying video, silent H.264 MP4 is the primary candidate and silent VP9 WebM is the fallback candidate. The Homebrew FFmpeg and Apple QuickTime Player builds in Section 6.1 are reference products for the AVC decision. The H.264/AAC and VP9/Opus paths in this audit are broader reference profiles.

The baseline contains only repository metadata. This audit covers an exact candidate npm graph, the upstream terms cited below, and binaries observed on one macOS ARM64 host. Pilot approval requires review of the actual package and runtime.
